## 🚀 Features

1. **Academic Minimalist Design (Matt Chapman Style):**
   - Clean split-layout with a sticky left sidebar containing avatar headshot, academic title, quick actions, and GitHub links.
   - Main content column featuring shields.io tech badges, crisp typographic hierarchy, and clean section dividers.
2. **Interactive Project Filtering:**
   - Filter projects on-the-fly by `All Projects (7)`, `AI & Machine Learning`, `Web Development`, `Social Impact & Health`, and `Python & IoT`.
3. **Dedicated Print-to-PDF Engine for VTOP:**
   - Single-click **"Print / Export PDF for VTOP"** button.
   - Built-in `@media print` CSS cleanly strips web navigation bars, theme toggles, and screen-only elements, delivering an immaculate, formal document formatted for PDF export.
4. **ScrollSpy Navigation:**
   - The sidebar highlights the current section as the reader scrolls through the portfolio.
5. **Light / Dark Mode:**
   - Clean academic light mode (default) and GitHub dark mode with local storage state preservation.
6. **Zero Dependencies & Blazing Speed:**
   - Pure semantic HTML5, modern CSS3 variables, and vanilla JavaScript.

## 🖨️ How to Export as PDF for VTOP Submission

1. Open `index.html` in your web browser.
2. Click the **"Print / Export PDF for VTOP"** button in the sidebar (or press `Ctrl + P`).
3. In the print dialog:
   - **Destination:** Select **Save as PDF**.
   - **Pages:** All.
   - **Layout:** Portrait.
   - **Options:** Uncheck "Headers and footers" for a clean look.
4. Click **Save** and name your file `Erin_Maria_Bobin_Web_Portfolio.pdf`.
5. Upload the resulting PDF directly to VTOP or paste the link as instructed!
