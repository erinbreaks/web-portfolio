1. SamjanSetu — AI-Powered Classroom Accessibility

Artificial Intelligence / Social Impact
🏆 Achievement: Selected among the Top 24 teams out of 120 teams in the Innovators Track

An AI-assisted classroom accessibility platform designed to help deaf and hard-of-hearing students participate more effectively in classroom learning through accessible, inclusive tools.

Key Features:
  • Converts live classroom speech into accessible real-time text.
  • Explores voice translation and support for Indian Sign Language (ISL) through an avatar.
  • Includes automated flashcards to reinforce learning and revision.
My learning: Introduced me to developing technology for social impact, designing user-focused solutions, and presenting under hackathon constraints.
🚀 Live Website GitHub Repo

2. EntryX — Event Ticketing & QR Check-In System

Web Development

An event ticketing web application designed to simplify registration, attendee confirmation, and on-site check-in verification using unique QR codes.

Key Features:
  • Event creation with custom ticket pricing and seat capacity limits.
  • Instant email confirmations with attached unique QR-based tickets.
  • Camera QR scanning and token entry for gate check-in.
  • Duplicate check-in prevention to prevent ticket reuse.
My learning: Explored web application structure, QR verification pipelines, and defensive handling against invalid or repeated entries.
GitHub Repo
