1. SamjanSetu — AI-Powered Classroom Accessibility

Artificial Intelligence / Social Impact
🏆 Achievement: Selected among Top 24 Teams out of 120 Teams in the Innovators Track

SamjanSetu is an AI-assisted inclusive classroom accessibility platform conceptualized and engineered to help deaf and hard-of-hearing students participate seamlessly and equitably in real-time academic lectures. The system bridges critical communication divides between teachers and differently-abled students through multimodal accessible learning interfaces.

Key Features and Architectural Objectives:
  • Real-Time Classroom Transcription: Converts live spoken educator speech into accessible, synchronized text streams.
  • Indian Sign Language (ISL) Avatar Synthesis: Explores translation of audio content into animated ISL gestures via an interactive avatar.
  • Automated Flashcard Generation: Leverages natural language processing to extract core lecture concepts into active recall flashcards for post-class revision.
  • Universal Classroom Inclusion: Eliminates pedagogical barriers for students requiring assistive hearing technologies.
Key Engineering Learning: Introduced me to human-centered design for assistive technology, handling real-time multimodal inputs, designing high-contrast accessible user flows, and pitching a working prototype under competitive hackathon judging criteria.

2. EntryX — Event Ticketing & QR Check-In Verification System

Web Development / Full-Stack

EntryX is an end-to-end event ticketing and attendee management web application built to streamline collegiate and commercial event registrations, ticketing pipelines, and physical gate admissions through cryptographic QR codes.

Key Features & Technical Implementations:
  • Dynamic Event Administration: Organizers can publish custom events with seat capacity limits, tiers, and pricing schedules.
  • Automated Dispatch Engine: Instant generation and email dispatch of secure ticket PDFs carrying unique participant tokens.
  • Optical QR Scanner & Fallback Entry: High-speed gate check-in via camera feed scanning, alongside manual token entry for degraded network conditions.
  • Duplicate Check-In Safeguard: Real-time state verification preventing ticket replay attacks or reuse of duplicate passes.
Key Engineering Learning: Deepened practical competence in stateful web application design, transactional integrity during ticket purchase, asynchronous email dispatch pipelines, client-side video stream processing, and defensive validation against concurrent check-ins.

3. Iris Flower Classification

Machine Learning / Data Science

A foundational machine learning classification study implementing end-to-end supervised learning workflows. The model processes morphological floral dimensions (sepal length, sepal width, petal length, and petal width) to accurately predict taxonomic species categories.

Key Learning Objectives & Methods:
  • Exploratory Data Analysis: Statistical profiling, distribution visualization, and feature correlation matrices.
  • Feature Engineering & Boundary Mapping: Analyzing mathematical separation among Setosa, Versicolor, and Virginica classes.
  • Model Training & Validation: Evaluating classifier algorithms, baseline splitting, and confusion matrix diagnostics.
  • Inference Pipeline: Structured prediction function taking raw geometric attributes to return class probability distributions.
Key Engineering Learning: Provided fundamental rigor in understanding tabular dataset preprocessing, avoiding data leakage during train/test splits, model evaluation metrics (precision, recall, F1), and interpreting decision boundaries.
View GitHub Repository

4. MediCycle — Responsible Medicine Reuse & Redistribution Concept

Healthcare / Social Impact

MediCycle is a healthcare innovation platform concept designed to tackle critical pharmaceutical wastage while extending medical access to underprivileged communities. It establishes a controlled, verified circular redistribution network connecting patient donors, certified pharmacists, NGOs, and low-income beneficiaries.

System Concept & Safety Principles:
  • Verified Donation Pipeline: Reallocating unexpired, sealed surplus prescription medications from households to certified relief dispensaries.
  • Pharmacist-in-the-Loop Verification: Mandatory clinical audit stage requiring authorized personnel to inspect blister integrity, expiry, and storage conditions.
  • Community Trust Architecture: Strict ethical and legal compliance guarding against the circulation of scheduled drugs or damaged packaging.
  • Geo-Dispensary Directory: Connecting donors with authorized collection hubs and drop-off points.
Key Engineering Learning: Challenged me to balance technical convenience against stringent healthcare regulations, patient safety liabilities, user privacy, and building trust in community-driven redistribution systems.

6. VIT Student Marketplace — Campus Trading & Rental System

Python Programming / Systems

A comprehensive Python-based software application engineered to streamline the buying, selling, searching, and renting of second-hand essentials within the VIT student ecosystem. It optimizes the lifecycle of academic textbooks, lab equipment, electronics, and hostel essentials.

Key Program Features & Implementation:
  • Robust Listing Engine: Add, edit, and categorize items with metadata including price, item condition, category, and seller contacts.
  • Keyword Search & Multi-Criteria Filtering: Fast indexing across listings by keyword matching and category filters.
  • Wishlist & Availability State Machine: Mark items as reserved, rented, sold, or active across multiple user sessions.
  • Persistent File I/O Serialization: Seamless persistence through structured CSV read/write pipelines, preventing data loss across program restarts.
Key Engineering Learning: Solidified foundational software engineering principles in Python: modular function architecture, dictionary/list manipulation, error handling for corrupted records, and building reliable data storage mechanisms without heavyweight database dependencies.

Multidisciplinary Project / IoT
